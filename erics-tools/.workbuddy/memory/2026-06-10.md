### 发现并修复的 Bug
1. **hash-generator.html MD5 实现完全损坏**：
   - `md5cycle` 函数轮次索引错误（`blk[22]` 越界，7~15 索引全部错位）
   - `hex()` 输出格式错误：只输出 8 字符而非 32 字符（`slice(-2)` 截断了每个 32 位整数的低位）
   - 替换为正确的 MD5 实现（修正全部 64 轮操作索引 + `padStart(8,'0')` 输出）
2. **hash-generator.html Web Crypto API 调用错误**：
   - `algo.replace('-', '').toLowerCase()` 将 `"SHA-256"` 转为 `"sha256"`，但 API 需要 `"SHA-256"`
   - 直接传 `algo` 原值修复
